
# Лабораторна робота №2

**Дисципліна:** Технології та фреймворки реактивного програмування 

**Виконала:** Петросян Карина  
**Група:** ІН-403  
**Варіант:** №1  
**Тема:** Система «Факультатив»

## Мета роботи

Навчитись створювати застосунок з використанням
реактивних технологій Spring Reactive Web.

## Індивідуальне завдання

Система «Факультатив».

Існує перелік курсів, за кожним з яких закріплений один викладач. Студент записується на один або кілька курсів, дані про реєстрацію зберігаються. Після закінчення навчання викладач виставляє студенту оцінку, яка зберігається в архіві.


## Використані технології

- Java 25
- Spring Boot 4.1.2
- Spring Reactive Web (WebFlux)
- Apache FreeMarker
- Lombok
- Maven
- Git та GitHub

## Структура проєкту

- entity — класи-сутності
- controller — REST-контролер
- handler — обробники HTTP-запитів
- router — маршрутизація запитів

## Сутності системи «Факультатив»

- Student — студент
- Teacher — викладач
- Course — факультативний курс
- Enrollment — реєстрація студента на курс
- GradeArchive — архів оцінок

## Тестування застосунку

Реалізовано тестові маршрути:

- GET / — головна сторінка
- GET /hello — тестове привітання
- GET /users — список клієнтів
- GET /clients — список клієнтів

Локальна адреса застосунку:
http://localhost:8080

## Результат

Створено реактивний Spring Boot застосунок,
реалізовано тестові HTTP-маршрути та розроблено
класи-сутності відповідно до індивідуального
